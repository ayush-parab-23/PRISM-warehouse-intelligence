# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in PRISM:
1. Please do not open a public issue.
2. Send details of the vulnerability to the project maintainers directly or report it privately through GitHub's Security Advisories tab.
3. Include the affected component, step-by-step reproduction instructions, and proof of concept if available.
